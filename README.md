# Some Shared Undergraduate Resources for BNU Physics Majors

这里整理北京师范大学物理学专业本科阶段可分享的学习资料，包括自写课程作业、实验报告、讲义和代码。仅收录作者明确选择公开分享的内容；不包含第三方教材/论文、个人申请材料、同学资料、隐私信息或 LaTeX 构建缓存。
