# Some-Shared-Undergraduate-Resources-for-BNU-Physics-Majors

北京师范大学物理学专业本科课程资料：作业、笔记、实验报告、课件和少量竞赛、科研记录。实验报告中的姓名和学号已换成「学生」和 `[学号已脱敏]`。

这里没有放入教材全文、英语听力原包、证书扫描件、支教队员材料和个人录像。只有 Git LFS 指针、本地没有文件实体的大文件也没有放入。
