	\section{数据的处理}
	在Python中，我们常用Numpy这个外部库来储存数据。这个库也包含一些最基础的函数运算。
	\subsection{Numpy的安装}
	对Win电脑而言，可以通过进入cmd输入指令来安装外部库。通过输入pip install <库名>，可以有安装绝大部分的库。通常的，我们可以通过搜索引擎或向ChatGPT告诉自己的需求，就能知道所能完成功能的库。
	
	Numpy是用于数据处理必不可少的库，我们可直接输入pip install numpy下载此库。
	
	\begin{minted}
		pip install numpy
	\end{minted}
